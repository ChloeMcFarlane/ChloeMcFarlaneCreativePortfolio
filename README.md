# Chloe McFarlane Creative Portfolio

A modern, responsive creative portfolio website built with Bootstrap 5 and custom styling.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Bootstrap Navigation**: Clean, professional navigation bar with smooth scrolling
- **Professional Typography**: Uses Google Fonts (Playfair Display for headings, Montserrat for body text)
- **Portfolio Grid**: Showcase your creative work in a beautiful grid layout
- **About Section**: Tell your story and connect with visitors
- **Contact Form**: Easy way for potential clients to reach out
- **Smooth Animations**: Elegant scroll animations and transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5.3.2
- Google Fonts (Playfair Display & Montserrat)
- Bootstrap Icons

## Setup

Simply open `index.html` in your web browser to view the portfolio. No build process or dependencies required!

## Customization

### Fonts
The portfolio uses two professional font families:
- **Playfair Display**: Elegant serif font for headings
- **Montserrat**: Clean sans-serif font for body text

These fonts are loaded from Google Fonts and can be customized in the `<head>` section of `index.html`.

### Colors
Color scheme can be customized by editing the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #34495e;
    --accent-color: #1abc9c;
    --light-bg: #f8f9fa;
    --text-color: #333;
    --text-light: #6c757d;
}
```

### Content
1. Update the text content in `index.html`
2. Replace portfolio item placeholders with your actual projects
3. Add your social media links in the About section
4. Customize the contact form or integrate with a backend service

- **Portfolio**: Grid showcase for creative work (6 placeholder items included)
